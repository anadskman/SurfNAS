# 4/8/2026 8 PM - Made firmware for oled and button

_Time spent: 2h_

Plugged in the OLED and got it detected over I2C. Installed the required Python libraries, but because of the new Python restrictions, I had to make a virtual environment to run everything properly.

After that, I wrote a script to control the OLED. It displays useful info like the device name (SurfNAS), CPU temperature, website status, and the local IP address. It updates every few seconds so it’s basically a live status screen for the server.

For cooling, the fan is just wired straight to 5V and GND so it stays on all the time. It’s quiet enough so there’s no need to control it with software.

I also added a button connected to a GPIO pin, which runs a script to safely shut down the Pi when pressed. This avoids just cutting power and potentially corrupting the system.
